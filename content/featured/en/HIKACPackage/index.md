A user-friendly Python package designed to simplify data extraction from Hikvision Access Control (AC) devices. This package allows developers and system integrators to efficiently fetch only the data they need, directly from device requests, without dealing with complex protocols or low-level communication.
Available on [PyPI](https://pypi.org/project/hikac/) and [Github](https://github.com/yusufjonc07/hikac).
